# Design assets (not published)

Source files kept for re-exporting. Nothing in this folder ships with the site.

- `logos-original/`: the 1200x260 client and partner logo PNGs. The site uses
  600x130 WebP copies in `public/logos/`. To re-export one, resize to 600x130
  and save as WebP (quality 90).
- `call-original/qr-menu-screen.png`: source for `public/call/qr-menu-screen.webp`.
